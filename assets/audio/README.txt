# Música Opcional para la Página

Por defecto, la página incluye un sintetizador Web Audio API que genera una hermosa melodía acústica suave sin requerir ningún archivo externo.

Si deseas utilizar tu propia canción favorita (por ejemplo una balada en MP3):
1. Coloca tu archivo de audio en esta misma carpeta (`assets/audio/`).
2. Nómbralo exactamente `musica.mp3`.
3. El reproductor detectará automáticamente `assets/audio/musica.mp3` y la reproducirá al pulsar el botón flotante 🎵 de la esquina superior.
